# 果冻狂奔 · Jelly Rush

全自动、随机、末位淘汰的横版大逃亡观赏游戏。设定好选手后全程自动比赛，只剩最后一名时结束，单局约 2–3 分钟。

整个游戏只有一个 `index.html`，没有依赖，也不需要构建。

## 在线游玩

启用 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

网址后加 `?watch` 可直接进入纯观赏模式自动连播：

```
https://<你的用户名>.github.io/<仓库名>/?watch
```

### 启用 GitHub Pages

1. 把本目录推送到 GitHub 仓库的 `main` 分支。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 里，Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等一两分钟，页面顶部会显示访问地址。

## 本地游玩

直接双击 `index.html` 用浏览器打开即可。

## 首页

打开后是首页，背景是一局自动进行的演示比赛。「开始狂奔」按当前配置直接开赛，「自定义配置」进入选手、资源包、地图等设定。

## 玩法

- **淘汰**：左侧的「吞噬者」持续逼近，被追上即出局；每隔一段时间「天雷裁决」劈掉当时的最后一名。只剩两人时出现终点线，先冲线者夺冠。
- **选手**：2–16 人，每人 30 点属性（速度、爆发、跳跃、耐力、稳定、幸运）和一个被动特性。比赛由运气主导，属性只让天平稍微倾斜。
- **资源包**：果冻原味、三国名将、水浒三十六天罡、百家姓、美食、元素周期表、扑克牌、AI 模型、漫威英雄、中国省份，可混搭。AI 模型包默认显示自绘的简化徽记；把图标文件放进 `icons/ai/` 即可替换成你自备的图标，文件名见 [icons/ai/README.md](icons/ai/README.md)。
- **地图**：草原、火山、雪山、太空、水世界、森林、迷幻，各有不同的地形倾向。
- **音乐**：每张地图 3 首背景音乐，由浏览器实时合成（没有音频文件），节奏随比赛进程加快。
- **种子**：同一个种子、同一份名单会重现同一局比赛。

## 操作

| 操作 | 说明 |
|---|---|
| 空格 | 暂停 / 继续 |
| Esc | 返回设定界面 |
| 双击屏幕 | 纯观赏模式下返回设定界面（触屏设备用） |
| 右上角按钮 | 1× / 2× / 4× 速度、暂停、声音（全开 / 仅音效 / 静音）、退出 |

手机上建议横屏观看。
